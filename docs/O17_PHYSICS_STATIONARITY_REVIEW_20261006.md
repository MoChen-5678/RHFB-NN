# 论文对照后的 O17 自洽性检查

2026-10-06。本次检查使用已经保存的真实 Python/PyTorch O17 神经网络密度，未重新训练、未使用 Fortran、未覆盖原结果。奇核求解器仍未通过物理验收。

## 方程与检查范围

[Geng–Long 的 RHFB 推导](https://arxiv.org/pdf/2202.00482)，式(21)–(23)，以正常与反常密度的变分构造自洽场；第7页说明奇核需要阻塞。[Robledo–Bertsch](https://arxiv.org/pdf/1205.4443)，第3节，说明阻塞态仍是广义密度纯态，并需重新变分时间奇场和比较多个候选。这意味着粒子数接近整数、结构误差小和网络参数更新，并不足以判断核已经求解。

本次从保存因子构造

\[
R=\begin{pmatrix}Q\rho_aQ^\dagger&Q\chi_aQ^T\\-Q^*\chi_a^*Q^\dagger&1-Q^*\rho_a^*Q^T\end{pmatrix},\qquad
W=\mathrm{diag}(Q,Q^*),\qquad C=[H-\mu N,R]W.
\]

正常场 `hQ` 是当前已实现完整 PKA1 粒子—空穴泛函对正常密度的导数，保留密度依赖与重排；配对场 `Delta Q*` 从同一保存的反常密度用强度1的 D1S 重算。拟合化学势以去除粒子数切向方向后，分别保存活动输出 `W†C` 和活动空间外输出 `C-WW†C`。计算过程中禁止调用场 Hamiltonian 谱求解。

这是一项必要的**未投影**方程诊断，只覆盖活动 Nambu 输入列，不能认证遗漏空间中的全部配对输入。它也不能替代无海处方。[DIRHB 论文](https://arxiv.org/pdf/1403.4039)，式(41)–(48)，区分 Dirac 分支与普通准粒子正负伙伴；严格正常场投影和完整准粒子分支的条件不能混用。详细区别及解析例子见[物理方程报告](RHFB_PHYSICAL_EQUATIONS_DECISION_20261006.md)。

## RHF-e 接触项的同处方对照

独立使用本地 RHF-e 球形迹公式核对 Hδ 补偿总能；独立球形径向核同时作为有限程加补偿项的数值对照。只有一个时间反演对称的中子1s双重态，质子真空；不是实际 O17，也不是所有时间奇态的验证。

先发现 reference 默认七点而 O17 使用五点，已将 reference 参数明确为五点并保存旧七点记录。固定盒半径6.5 fm，仅作一次网格细化：

|rho-T 有限程加 Hδ|14.2528|3.45705|

## ADF 与下一步的物理约束

[张颖等论文](https://csnsdoc.ihep.ac.cn/article/doi/10.1088/1674-1137/ad806f)，五点前后向差分是径向空间导数的四阶精度格式。O17 中该设置用于 Dirac 径向导数和 Green 顶角；参数梯度仍由自动微分计算。Dirac 非对角块互为转置与论文的 Hermiticity 逻辑相符，但 Green 顶角使用独立的标量多极导数及加权伴随；不能将 Dirac Hermiticity 直接当作完整 rho-T/pi Green 核已经物理正确的证明。原点边界逐项对应仍需验证，详见[ADF 审计](RHFB_ADF_AUDIT.md)。

下一步先完成同一无海处方、同一阻塞候选下的独立参考比对，明确活动空间内外允许的驻定方程，再将这些方程纳入实际网络训练；继续保留完整 PKA1、强度1的 D1S、时间奇源和一般形变。不能仅增加训练轮数、改变配对强度或把另一个投影问题的更小残差当作 O17 已求解。

## 同步实施的小空间原型，均未验收

Luna 已新增独立投影固定点接口及 SiLU 网络桥接，正常场自洽，D1S 配对场随当前反常密度重算，残差对投影和场的依赖保留自动微分。这些有限8态原型不是完整 PKA1 核计算，也没有改变原双投影能量变分候选的待验状态。

- [固定点候选与独立参考](projected_rhfb_fixedpoint_benchmark_20261006.json)：在相同 N=3 的四个初始阻塞分支中选出 block2，再做有界、粒子数恢复的能量下降预热。候选4步最大残差 `1.08e-2`、粒子数误差 `8.03e-4`；独立参考2轮后粒子数误差 `0.853`，分支重叠裕度很小，二者均未收敛。当前固定重叠参考分支下的 `N(mu)` 单调性未证明，不能直接套用化学势二分法。首次参考辅助函数导入失败后，同配置重试已单独记录，没有据此作能量比较。
- [实际神经网络桥接试算](../outputs/validation/neural_fixedpoint_toy_20261006/REPORT.md)：block5、12步；训练的是204个输出层参数，隐藏 SiLU 特征固定。最大实数打包方程残差 `8.80e-5`，仍高于目标；正则坐标从最大约0.32增至640，参数范数大幅放大，不能把较小残差认作稳定解。配对趋小只是该分支的状态性质，尚不能判定为病理。它与 block2 的试算不能作同阻塞分支验收比较。

接口及必要代数测试通过，不构成这两份未收敛结果的物理认证。实际 O17 训练仍须等同处方参考和阻塞分支逻辑验证后继续。
