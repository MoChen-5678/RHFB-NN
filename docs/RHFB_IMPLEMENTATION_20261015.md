数目投影在当前约定下为

\[
B_0=h\chi+\chi h^*+\Delta-\Delta\rho^*-\rho\Delta,
\qquad
\mu=\frac{\operatorname{Re}\langle B_0,\chi\rangle}{2\|\chi\|_F^2}.
\]

只计算 Q†hQ、Q†ΔQ* 来求这个标量内积是精确因子化；完整残差中的 Δ 仍作用于所有原始空间方向，未裁去 Q 外配对。纯态满足约束 Gram=8||χ||²=4 Var(N)。数目响应奇异判据是浮点线性求解诊断，不是物理配对截断。该投影目前使用完整正则 HFB 切向；若之后采用受限的无海切向，必须重新推导相应的约束 Gram。

依据是 [Robledo–Bertsch 的约束梯度与 Thouless 变分，Eqs. (6), (8), (11)–(23)](https://arxiv.org/pdf/1104.5453)，以及 [Li 等奇核阻塞列交换](https://arxiv.org/pdf/1203.1363)。这些公式不是本项目相对论无海实现已经通过的证明。

## 已完成的独立核查

- U/V 密度与独立 Fock 空间期望值一致；单列 PH 交换与一准粒子态一致。测试发现并修正了参考态已交换后再次偏移 blocked 列的错误，同时覆盖粒子/空穴参考和 O17 子类的 QR 相位。
- H20 与直接 W†HW 的 20 块一致；能量方向导数与独立密度变分及数值导数一致。U/V 的数目投影和完整 R 的因子化投影相互独立且一致。
- 粒子数乘子及对场的响应梯度在仅授权的物理 GPU 1 上与 CPU 对照通过；未使用谱对角化或刷新来构造这些训练动作。
- 原 PKA1 球形 Python 泛函与新 m 表示采用同一归一化径向态、两种光滑物理扰动和三档 h=0.125/0.0625/0.03125 fm。最细网格各通道方向导数最大相对差约 0.2481%，最细/粗网格绝对差比为 0.0622–0.0733，显示趋近同一极限。此结果只覆盖所测球形静态方向，不代表粗网格 O17 或一般时间奇响应已验收。
- 两种实现的径向求积不同，逐网格能量梯度是带不同积分权的协向量，直接比较其欧氏范数或先作同一轨道投影都不成立。两次失败诊断保留；以共同光滑扰动的标量 δE 和网格收敛替代错误的跨离散比较，没有据此篡改传播子或放宽门限。
- 真实附件 PKA1 参数表与当前 Python 一致。BI/Broyden 和 S 的活动 D1S 参数及强度一致；BI 根版本的强度为交互输入，审计明确给出未确定差异，未猜成 1。

共 73 项去重测试通过，验证摘要及详细文件见 `outputs/validation/rhfb_physics_batch_20261015.json`。最终选取的各组作业均有已完成的内核保护证据，OOM/oom_kill 计数为零；主要组内存上限 3 GiB，最后的独立小空间参考上限 1.5 GiB，全部 swap=0。GPU 组仅使用物理 GPU 1、驱动预算 2 GiB。采样主存最大约 1.62 GiB；该内核未提供 `memory.peak`，不把采样值冒称为精确峰值。

本批没有启动完整 O17 核训练，没有生成新的已收敛 O17 数据；此前核数据保持其未收敛标记。小空间代数、导出和梯度测试不代替完整核的物理或资源验收。

## 仍需补齐的物理问题

1. 无海与准粒子求和约定。附件的主自洽源省略部分准粒子贡献，不足以直接证明全 Dirac 空间 χ 严格反对称或广义密度严格纯。[DIRHB Eqs. (43)–(48)](https://arxiv.org/pdf/1403.4039)明确讨论省略负海准粒子贡献后的近似反对称性；负能 DWS 展开基的完备性是另一问题，见 [Geng–Long Sec. III.A](https://arxiv.org/pdf/2202.00482)。必须先对齐求和/变分处方，不能强求两种不同近似下的密度逐点相等，也不能用固定 P+ 或任意能窗掩盖不一致。
2. 在已定义并验证的物理分支上接入能量变分、粒子数误差校正、局部稳定性和多阻塞候选排序。现有残差平方目标仍可能收敛到激发驻点；本批 H20 动作是必要基础，未把它冒称为完整最低解流程。
3. 时间奇/一般形变的独立场基准，径向/角向/活动空间收敛、动量算符与质心修正、准粒子物理身份追踪仍需验收。源码的球形 J=0 及简并权修正只在其对应范围内作参照。

原全量备份与入库原件校验记录保持不变；本批另有变更前源码快照。所有数值测试经实际内核 cgroup、swap=0、共享单作业锁及超时保护，GPU 作业只允许物理编号 1。各次保护证据单独存档；不使用声明式内存估算替代内核限制。

### 无海源截断的独立小空间反例

新增 `source_completeness_reference.py`，仅在独立参考中求解两个 8×8 BdG 矩阵，训练入口显式拒绝调用。模型有一个海能级和三个 Fermi 能级，未配对支标签可解析确定；配对扰动的行和界严格小于已分离的两簇能谱间隔。因此该参考的支标签有明确依据，不建立一般 NN 固定能窗规则，也不估算 O17 误差。

在海/Fermi 配对耦合为零时，完整混合支求和与省略支求和均满足纯态/反对称结构；当该参考耦合设为 0.8 MeV 时，省略支的 V 范数平方约 1.81×10⁻⁷，但省略后的 χ 反对称误差为 6.02×10⁻⁴、R 幂等误差为 4.77×10⁻⁵。只把 χ 强制反对称后，幂等误差仍约 3.37×10⁻⁵。保留完整求和的结构误差约 10⁻¹⁴–10⁻¹⁵。

数据见 `outputs/validation/rhfb_source_completeness_20261015.json`，保护记录和两项测试同名存档。此参考做了两次独立谱求解，NN 训练谱求解和刷新均为零；没有 Fortran 调用。该反例说明“省略贡献很小”不能升级为严格纯态恒等式。在当前完整正则 NN 模型下，后续无海目标应保留与正则结构一致的完整准粒子求和，再验证无对角化实现；附件的省项处方仅作其近似范围内的对照。
