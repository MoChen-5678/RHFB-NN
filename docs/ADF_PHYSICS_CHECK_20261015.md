# ADF and G/F check for the O17 run

## What `derivative_order=5` means

In the O17 configuration, `derivative_order=5` selects a **five-point asymmetric finite difference**, not a fifth-order-accurate derivative. The forward rule is

\[
D_+f_i=\frac{-25f_i+48f_{i+1}-36f_{i+2}+16f_{i+3}-3f_{i+4}}{12h},
\qquad D_+f_i=f'(r_i)+O(h^4),
\]

and the backward rule printed by Wang, Cao, Hu, and Zhang has the reflected coefficients, also with \(O(h^4)\) error (2025, Eqs. 13–14, article p. 3, 014106-3). Thus “5” counts stencil points; it is neither a finite difference over neural parameters nor a claim of fifth-order convergence. [Journal article](https://csnsdoc.ihep.ac.cn/article/doi/10.1088/1674-1137/ad806f) · [publisher PDF](https://cpc.ihep.ac.cn/fileZGWLC/journal/article/zgwlc/2025/1/PDF/CPC-2024-0503.pdf)

For the reduced radial Dirac components, the upper/large \(G\) component has origin extension parity set by \(l_G\); the lower/small \(F\) component has the opposite parity. The code alternates forward and backward assignments accordingly. It defines \(D_-=-D_+^T\); with the two off-diagonal blocks \(B_1=-D_{\rm backward}+\kappa/r\) and \(B_2=D_{\rm forward}+\kappa/r\), this makes \(B_1=B_2^T\) and the assembled real radial Dirac matrix symmetric. Both directions use five points and fourth-order interior accuracy: the difference is orientation, not accuracy order. The paper warns that using one direction for both components can make the Dirac matrix non-Hermitian and recommends alternating by component parity (Sec. II, text around Eqs. 13–15, article p. 3). The implementation and focused checks are at [`dirac.py`](../dpl_rhf/rhf/dirac.py#L16) and [`test_zhang_adf.py`](../dpl_rhf/tests/test_zhang_adf.py#L1).

The O17 grid is a separate accuracy question. It uses \(R=8\,\mathrm{fm}\), \(h=0.8\,\mathrm{fm}\), nine interior radial points, \(|\kappa|\le3\), and angular quadrature \(7\times14\) ([seed run config](../outputs/demo/O17_neural_parity_candidate_20261006/run_config.json)); the five-point one-sided stencil spans four steps (3.2 fm). The Zhang paper’s worked FDM cases use \(h=0.1\,\mathrm{fm}\), \(R_{box}=20\) or 40 fm (Sec. II, article p. 3), with prescribed Woods–Saxon fields and model pairing. Therefore its stencil formula supports the interior discretization choice, but does not certify this coarser O17 grid, its eight-fm box, or the present self-consistent PKA1 functional. No error bar for the O17 derivatives follows from the formal \(O(h^4)\) statement alone. A mesh/box refinement comparison remains the smallest direct accuracy check.

There are two spatial ADF uses in the current implementation. The radial Dirac operator above differentiates reduced spinor amplitudes. [`GreenOperator`](../dpl_rhf/rhfb/spatial.py#L23) instead differentiates scalar multipole components: odd \(l\) uses forward ADF, even \(l\) backward ADF, with even-origin values reconstructed by an even-polynomial rule. Its vector derivative is paired with the exact weighted discrete adjoint in [`gradient_adjoint`](../dpl_rhf/rhfb/spatial.py#L134); this is the discrete integration-by-parts relationship used by derivative meson vertices. For this run the Green and Gaussian pairing multipole cutoff is \(l_{max}=2K=6\), resolved by the 7×14 angular grid. This finite representation is not an angular-convergence certificate. The local audit also records that boundary-row equivalence to the Zhang construction, especially the origin row, is not established ([`RHFB_ADF_AUDIT.md`](RHFB_ADF_AUDIT.md#L18)).

## Spatial derivatives are not neural parameter finite differences

The ADF differentiates functions on the physical radial/spatial grid inside the Dirac and interaction operators. Neural parameters are differentiated by PyTorch autograd: the training loop calls `old_loss.backward()` ([`selfconsistent_neural_training.py`](../dpl_rhf/rhfb/selfconsistent_neural_training.py#L886)), while the streamed PH energy/field custom VJP uses `torch.autograd.grad` and recomputes density blocks/Hessian-vector products ([`streamed_field_autograd.py`](../dpl_rhf/rhfb/streamed_field_autograd.py#L36)). Hence changing `derivative_order` changes the spatial model discretization, not the finite-difference step for the optimizer gradient. A centered finite-difference parameter check, where used by tests, is an independent diagnostic.

## What “full G/F pairing” means here

In the D-RHFB literature, \(G\) and \(F\) label the large and small Dirac radial components. Geng and Long explicitly use finite-range Gogny D1S for pairing (Eq. 30), sum the pairing tensor and gap over \(\sigma,\sigma'=\pm\) (Eq. 31 and Appendix B Eqs. B1–B4), identify \(+/-\) with \(G/F\), and state that their axially deformed calculation includes all \(J\) components rather than only \(J=0\) (Appendix B, PDF p. 25). These are component blocks of the pairing tensor/gap; they are **not** forward/backward derivative orders, and D1S pairing itself has no radial derivative stencil. [Geng & Long, arXiv:2202.00482](https://arxiv.org/abs/2202.00482) · [PDF](https://arxiv.org/pdf/2202.00482)

The present D1S action samples all four Dirac components and applies its full-space gap action to arbitrary primitive vectors; its inputs enforce \(\chi^T=-\chi\), and its active gap is explicitly antisymmetrized ([`gaussian_pairing.py`](../dpl_rhf/rhfb/gaussian_pairing.py#L105), [`pairing_action.py`](../dpl_rhf/rhfb/pairing_action.py#L15)). The literature therefore supports retaining G/F pairing sectors as a model choice. It does not by itself prove exact numerical equivalence of this unrestricted three-dimensional implementation to the axially deformed spherical-DWS expressions, nor remove the run’s \(L\le6\), \(M=42\), \(D=432\) representation limits. Component completeness and Hermiticity/antisymmetry are structural checks; grid, angular-cutoff, and functional-closure convergence remain distinct validations.
