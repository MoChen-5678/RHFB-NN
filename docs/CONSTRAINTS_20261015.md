# O17 当前训练条件及依据

用户要求所有物理约束有物理依据。本表区分态的物理结构、已选模型、离散近似和运行保护；数值阈值不宣称为自然规律。

| 条件 | 性质及依据 | 当前实现与限制 |
|---|---|---|
| 中子数 N=9、质子数 Z=8 | O17 定义；HFB 中约束的是期望粒子数 | 目标进入驻定与粒子数目标函数；实际误差逐步输出，不能仅凭目标存在就宣布达标 |
| 中子奇、质子偶的费米子数奇偶性 | 偶二次正则变换保持初始 HFB 真空的费米子数奇偶扇区；Robledo–Bertsch | 从显式奇参考生成纯态，检查实际奇偶性；不是人为的空间宇称或形变约束 |
| Q 正交，rho 厄米，chi 反对称，广义密度幂等 | 零温纯准粒子真空的正则结构及费米反对易关系 | 正则参数化和误差检查；检查容差只是浮点验收值 |
| PKA1 粒子—空穴道，D1S 强度 1 的 nn/pp 配对 | 用户选定的模型；Geng–Long 给出形变 RHFB 实现先例 | 不意味着奇核三维延拓已验证；pn 缺失属于明确的模型边界 |
| 密度依赖取四流不变量 | 协变密度依赖的动机见 Fuchs 等；原静态 DDRHF 文献取 j0 | 当前显式延拓，空间重排从同一泛函求导；仍需奇核外部基准，不作为已认证处方 |
| 无海变分分支 | 相对论核 DFT 的物理处方需要与配对驻定条件一致 | 当前优化器尚未给出已验证的分支约束。不得补任意 W、海占据阈值，或宣称双投影等价 |
| 阻塞身份 | Schunck 等的重叠追踪有定义的单粒子标签及准粒子候选 | 当前 R-only tag 仅作诊断；没有 0.90 或其他重叠接受门槛，也没有身份认证 |
| 原始空间、M=42、有限盒、ADF 网格、角截断 | 用户计划指定的数值近似和当前运行规格 | 不限制一般形变或空间宇称；需扩大空间才能证明收敛，现规格不是物理定律 |
| 梯度裁剪、学习率、损失下降回溯 | 优化器的有限步数值控制 | 不对能量、形变、阻塞标签或海占据增加可接受态条件；残差下降也不能认证能量极小值 |
| cgroup 主存上限、无交换、显存预算、单任务、分块重计算 | 服务器运行保护 | 保留；不是物理约束，不通过缩小 O17 物理空间来回避内存问题 |

当前 O17 入口已移除旧解码器的空间宇称掩码；转换时检查同一初态的 Q、rho、chi 与正则变换一致。该初态等价核对不是优化中的列重叠约束。保存的参数化列重叠不得解释为物理准粒子身份。

参考：[Robledo–Bertsch](https://arxiv.org/abs/1104.5453)、[Schunck 等](https://arxiv.org/abs/0910.2164)、[Geng–Long](https://arxiv.org/abs/2202.00482)、[Long 等](https://arxiv.org/abs/nucl-th/0608009)、[Fuchs 等](https://doi.org/10.1103/PhysRevC.52.3043)、[DIRHB](https://arxiv.org/abs/1403.4039)。
