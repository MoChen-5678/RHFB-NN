# PotelHF 参考程序修复与 NN 检查（2026-11-05）

## 范围与结论

使用用户上传的修正版 `PotelHF.f90`。与存档 S-RHFB-C 的文本差异仅为原
54–57 行与 59–62 行交换位置。两套实际重算源码中的该文件与附件逐字节一致。

Claude Code 最新 v2 数据包实际含 72 条记录、69 个不同核素，并非早期报告的
70 条。3 个重复核（Sn132、Pb208、Pb210）分别在 production 和 dripline 中
保留各自 NN 结果。此次完成全部 69 次参考计算，更新了全部 72 条记录。
原程序、旧结果包、NN 摘要和模型参数均保留；论文文件未修改。

## 错误机制

旧代码在 PKA1 的 `gotn=0` 分支执行 `cycle`，跳过后面的 rho 张量积分循环。
因此 rho 张量有限程项及矢量–张量直接项缺失，而循环后的 `2/3` 接触项仍保留。
这解释了旧输出的 rho 张量直接项并非零、混合直接项却为零。
交换代码块后恢复了这些项。此结论与修复针对本次 PKA1 数据集。

NN 的 `dpl_rhf/rhf/direct.py` 在 PKA1 下独立计算 rho 张量及混合直接项，
没有上述 omega 张量分支造成的跳过。此次未修改 NN 泛函、梯度、训练代码或权重。

## NN 检查的界限与能级说明

72 份保存态的粒子数误差 ≤5.69e-14，正交误差 ≤2.45e-15，Hamiltonian 厄米性误差
为 0；无海投影均收敛，最大自洽海泄漏为 1.122e-10。训练 Dirac 求解与刷新计数为 0。
但最大轨道驻点残差仍为 0.137818 MeV，占据残差为 0.001055 MeV。
场变化达到停止阈值不能替代严格变分残差和模型空间收敛研究。

`SphericalRHFBBackend` 报告的 `h_nn_mev` 是保存轨道上的 `<phi|h|phi>`，
并非 Hamiltonian 本征值；`principal` 沿用轨道标签。占据接近 0 或 1 时，
内部轨道旋转可以明显改变这些对角元，而总密度和能量变化很小。
因此按 `(species,kappa,principal)` 对照的数值不是已经验证的本征能谱精度。
最新 v2 的 Sn132、Pb208、Pb210 正则对角元对照 MAE 分别约 2.177、1.768、2.225 MeV
（只统计 NN v²>0.05 的态），不支持沿用旧 README 的较小能级 MAE。
此处保留原始数值，在能级表增加能量定义和匹配方法列，更新 README 的表头与说明，
没有通过排序或修改 NN 数据消除差异。本轮未验证真实 Hamiltonian 本征能谱。

所以，此次结论是“未发现 NN 对应能量通道的同类实现错误”，并非对整个 NN 程序
或所有精度指标作无条件正确性保证。
