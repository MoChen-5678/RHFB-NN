# RHFB 物理模块接入神经网络主程序

2026-10-15。本次在 `variants/blocked-rhfb` 修改代码并验证，不运行 O17，也不编译或运行 Fortran。用户提供的两个 RHFB 程序仅用于只读核对。原程序、旧结果及完整备份保留。

## 已接入的实际流程

1. 网络生成复正交轨道与正则 Bogoliubov 态；奇态从明确的阻塞参考构造。新增持久化的正则输运矩阵，把平均粒子数校正写回网络的实际前向态。不是仅校正导出的密度。输运保持粒子数奇偶性；无数目响应时报告失败，不注入人为配对。
2. 初始化及每个优化试探先校正实际网络态，再重算现有完整 PKA1 粒子—空穴泛函和 D1S 配对场。回退同时恢复权重、正则输运和优化器；检查点保存实际输运。旧检查点只可显式转换为初态，不能冒充可续训的新检查点。
3. 主训练器新增可选的完整 Nambu 分支目标。它读取每次评估的完整 h、全部配对场列和实际 μ，保留场响应；通过有理近似及线性求解构造小空间目标，不提取训练本征矢、不刷新网络空间。精确场证据变化后立即拒绝，不能退回其他目标继续训练。
4. 奇态目标要求当前场下的阻塞模证据，检查本征残差、粒子—空穴伙伴占据及最终密度的 Pfaffian 奇偶性。普通的网络列标签不能充当瞬时准粒子证据。场族 provider 还必须在自动微分图中连接当前 H；零响应允许，但独立可训练叶子会被拒绝。这项检查仅证明图连通，不证明导数正确。
5. 新增一般 m 空间 ADF 动量及独立 p²，接入主程序的变分后质心报告。G/F 各用自己的角动量与径向原点奇偶性。p² 从空间导数内积独立计算，不用有限空间中的 p 矩阵平方代替。矢量 p 使用分部积分弱形式；同时保留原始 ADF 矩阵及分部积分缺陷，不能把厄米化当作边界已正确的证据。质心项不参与本处方的训练场。

主接线：`dpl_rhf/rhfb/selfconsistent_neural_training.py`。核驱动 `o17_selfconsistent_neural.py` 已传递新接口并保存源码来源，但没有启动核计算。新分支目标仍需调用方提供证据；未提供时旧兼容路径始终标注无海未认证、物理结果未接受。

## 依据及处方边界

- Robledo–Bertsch，[梯度 HFB](https://arxiv.org/abs/1104.5453)：正则变分、平均数目约束校正与奇偶保持；这里的校正不是粒子数投影。
- 用户程序的 `S-RHFB-C/RHFB.f90:43`、`Dirac.f90:383` 及 `RHFB-BI/Broyden/Dirac.f90:317`：只读核对数目、阻塞及输出顺序。具体版本哈希见此前源码审计。
- [DIRHB Eqs. (46)–(48)](https://arxiv.org/abs/1403.4039) 与 [Long 等的 RHFB 推导](https://arxiv.org/abs/0812.1103)：负能展开基不等同于海占据，完整正常/反常密度不能用任意截掉全部负能分量代替。
- [Geng–Long Eq. (41)、Appendix C](https://arxiv.org/abs/2202.00482)：变分后质心修正及动量矩阵元。
- 当前有限能带的混合 sign 公式是本项目在显式能带分离假设下的代数构造，并非上述论文证明了它适用于一般核场。

## 已验证的内容

最终测试清单、逐项结果及内存保护证据汇总在 `outputs/validation/rhfb_neural_main_integration_20261015.json`，不重复累计中间重跑。

- 实际网络态的数目校正、正则结构、奇偶性、奇异拒绝；CPU 与物理 GPU 1 对照。
- 主训练初始化、试探、异常回退、断点续训；恢复态与连续训练一致。
- 人工四模自洽模型中的偶态和奇态完整 Nambu 目标；场和 μ 的响应；旧证据与断开响应拒绝。人工模型有解析能带证据及对称性固定阻塞模，不是 O17、也不替代核参考解。
- ADF 高斯解析 p² 以及矢量动量的两档网格比较；质心观察器不会改变训练态。
- 当前流式 PKA1 实现中，复杂、含空间流和轴矢流的单中子/单质子 rank-one 态，逐通道直接项与交换项抵消；π Hartree 在抵消前非零；接触项及轨道方向导数分别核对。
- 现有 PKA1+D1S 场导数、流式自动微分、导出、处方及用户源码模板回归。

所有数值验证均经内核 cgroup 内存上限、swap=0、超时及单任务锁。GPU 验证只用物理 GPU 1。独立小矩阵参考测试的常规谱求解与训练代码隔离。

## 尚未补齐，不能据此恢复 O17

1. 一般核场中，正能连续谱与海的绝对能带可能重叠。目前没有完整 O17 场族的能带分离证明，也没有经过独立核参考验证的分支追踪实现。不能随意选能量窗或投影来制造通过结果。
2. 当前分支目标是 D≤96 的条件原型。它不是已验证的完整核无海求解器，也不是能量极小判据。场族证据、阻塞模来源和其数学导数仍需要独立验证，标志始终为未认证。
3. 仍需核尺度的一般形变/时间奇场独立基准、完整质心空间收敛、多个阻塞候选与初始形变搜索，以及盒半径、网格、角向和活动空间收敛。

因此本次完成了若干真实主程序接线与物理恒等式检查；没有完成整个奇核求解器验收，没有新增 O17 能量、半径或 RHB 比较结果。O17 保持停止。
