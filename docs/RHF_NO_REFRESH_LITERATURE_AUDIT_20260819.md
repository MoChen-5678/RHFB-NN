# 无子空间刷新 RHF：文献、公式与实现审计

## 1. 结论

本实现直接优化占据一体密度矩阵的低秩因子，不在训练轮次中求解 Dirac
本征方程，也不重建或替换正能子空间。对每个核子种类、`kappa` 和主量子数，
网络产生正交占据因子 `Q`，并构造

\[
P_q^\kappa=Q_q^\kappa f_q^\kappa Q_q^{\kappa T}.
\]

PKA1 总作用量、密度依赖顶角、Hartree、全部 Fock 通道和重排项对 `P` 完整
可微。Core-1204 只在训练结束后验证，不提供训练标签、密度、场或能量。

## 2. 非局域密度

完整占据态指标是 `a=(q,kappa,n,m)`。球对称只消去显式的 `m` 求和并产生
`2j+1`，不能消去 `n` 或 `kappa`。程序严格构造

\[
R_{q\kappa}^{\mu\nu}(r,r')=(2j_\kappa+1)
\sum_n v_{qn\kappa}^2 u_{qn\kappa}^{\mu}(r)
u_{qn\kappa}^{\nu}(r'),
\]

其中四个 Dirac 分量依次为 `GG`、`GF`、`FG`、`FF`。实现顺序是：

1. 固定 `(q,kappa)`；
2. 在该块内先对不同 `n` 求和；
3. 磁简并度只乘一次；
4. 每个 Fock 通道再对源块 `(q_b,kappa_b)` 求和；
5. Hartree 局域密度由同一个 `R(r,r')` 的对角收缩得到。

因此 Fock 没有被局域化。测试覆盖四分量厄米关系、等占据 `n` 空间旋转
不变性、五个闭壳核的粒子数和投影幂等性。PKA1/O16 同 Core 密度闭合中，
总能量误差为 `4.01e-6 MeV/A`，净 Fock 误差为 `2.97e-5 MeV`。

## 3. 三个 Hamiltonian

程序分别构造

\[
h=h_{\rm kin}+h_D+h_E,
\]

其中 `h_D` 包含局域密度依赖重排，`h_E` 是完整非局域 Fock 泛函导数并避免
重复计入 Fock 重排。三个投影残差分别记录：

\[
r_i=(I-QQ^T)h_iQf,\qquad i\in\{\mathrm{kin},D,E\}.
\]

严格 Euler-Lagrange 约束是

\[
r_{\rm kin}+r_D+r_E=0,
\]

而不是 `r_kin=r_D=r_E=0`。Core 的收敛 O16 密度给出三个非零 RMS
`3.522/2.632/0.968 MeV`，但总残差仅 `0.179 MeV`，直接证明物理解依赖三者
抵消。程序逐项反传和监控，并对矢量和施加物理约束。

损失中的总约束按恒等式显式展开为

\[
\|r_{\rm kin}+r_D+r_E\|^2
=\|r_{\rm kin}\|^2+\|r_D\|^2+\|r_E\|^2
+2r_{\rm kin}\!\cdot r_D+2r_{\rm kin}\!\cdot r_E+2r_D\!\cdot r_E.
\]

六项均保留自动微分图并逐轮输出，因此非局域 Fock Hamiltonian 的自项及其
与动能、Hartree 的干涉项都会进入反向传播。程序另外检查该展开与原总残差
平方严格闭合；这使三个 Hamiltonian 的传播路径可独立审计，同时不破坏
Euler-Lagrange 方程要求的物理抵消。

## 4. 无海约束

Hamiltonian 已减去静质量，取 `W_q=-M_q`。每轮解线性方程

\[
(h_q-W_q I)X_q=Q_q
\]

但不求本征态。占据空间小矩阵

\[
K_q=Q_q^T(h_q-W_qI)^{-1}Q_q
\]

必须以全部本征值检查 `(-W_q)K_q >= I`。旧实现只检查对角元，结果依赖
占据轨道的任意旋转并可能漏掉 Dirac 海方向；现已修复为旋转不变的矩阵判据。
逆 Hamiltonian 辅助更新按文献固定当前 `h[rho_k]`，不把非物理的二阶
`dh/drho` 反馈混入无海演化；完整密度依赖仍通过总 RHF 能量反传。

## 5. Fock 梯度对抗与网络修复

错误密度路径上，网络梯度范数为

```text
kinetic 5.163, direct 4.011, Fock 1.271, total 0.093
```

余弦为 `kinetic/direct=-0.997`、`kinetic/Fock=-0.955`。Fock 已经进入反传，
但三个大梯度在错误的高密度路径上几乎完全抵消。为改善条件数，程序增加两项
不改变最终作用量的优化结构：

- 分别测量三个物理通道的网络梯度，并可使用退火到零的范数预条件；
- 加入严格边界保持的径向幺正膨胀生成元
  `delta u=-(1/2+r d/dr)u delta ln(s)`，随后仍由 QR 精确正交化。

膨胀坐标是密度因子的解析变分方向，不使用 SCF 数据。所有可学习非线性仍为
SiLU。
