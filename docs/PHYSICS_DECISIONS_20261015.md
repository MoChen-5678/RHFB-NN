# 奇核神经网络求解器：独立物理判断与证据

2026-10-15。三名 Luna 分别核查无海处方、阻塞与规范自由度、PKA1/D1S 泛函；主代理独立查阅原文并核验优化目标和存档数据。工作均在开发副本内，无 Fortran；没有产生新的 O17 自洽解。原完整目标仍未完成。

我的判断是：奇宇称 Bogoliubov 变分态用神经网络表示有依据；当前最主要的缺口是物理分支、最低能选择和连续谱/离散空间验收，不能用更多残差优化步骤替代。用户提出的方案及既有实现都须接受同样检查。

| 假设 | 当前判断 | 对实现的要求 |
|---|---|---|
| 纯态规范变换能够保持奇数粒子数宇称 | 文献支持；平均粒子数仍需独立约束 | 保留结构化参数化，区分宇称与平均粒子数 |
| 零驻定残差就是基态 | 明确不成立；下面有独立反例 | 驻定检查之外，在允许的物理变分空间内做能量选择/稳定性与多候选比较 |

| 正常场双投影与完整配对 RHFB 是同一问题 | 既有同场条件参考未通过此等价性 | 先固定无海处方，重新定义与其一致的参考和驻定条件 |

Robledo–Bertsch 的梯度法对受约束能量作变分，H20 的范数是收敛诊断，不能把该范数平方视为同一个能量优化问题。论文同时讨论局部极小值及不同初态搜索。[原文，Eqs.14–23、Sec.III、Sec.VII.B](https://arxiv.org/pdf/1104.5453)。

本轮构造了独立反例，而非引述论文数值。取两个正能单粒子能级 h=diag(1,2) MeV、严格N=1、chi=0。两个 Slater 态都满足相同纯度、奇宇称和零完整Nambu对易残差，但能量分别为1和2 MeV。对保持N=1的轨道旋转，能量曲率分别为+2和−2，残差平方的曲率却都为+8。较高能态因此也是残差目标的局部极小值。这在不涉及Dirac海的有界空间已经成立。验证程序无谱求解、无刷新，在1.5 GiB硬限额、swap=0下通过，见[结果](../outputs/validation/stationarity_minimum_20261015_attempt02/diagnostic.json)。首次曲率计算使用abs的非光滑AD路径而失败，原记录和源码保留；改用等价的实部平方加虚部平方后，与解析值一致。

由此不能直接跳到“最小化裸Dirac能量”：能量稳定性只应在已声明且正确实现的无海、粒子数和其他物理约束的允许切空间内讨论。现训练器仍为驻定残差原型，本轮没有切换泛函或优化目标。[逆Hamiltonian论文的范围](https://arxiv.org/pdf/1304.4697)也只是其指定场模型，不能作为本项目完整自洽相对论配对扩展的通用证明。

阻塞核查中，我赞同 Luna 对固定初态门槛的批评，也认为“逐步重叠”仍不足：若规范变换不改变R却改变被选中的列，列重叠下降就不能当作物理跳支。文献的最大重叠处方有明确单粒子标签及U/V准粒子候选，不能不加说明照搬到没有Hamiltonian对角化的网络参数列。[Schunck等，Sec.II.D、Eqs.15–16](https://arxiv.org/pdf/0910.2164)。这里只识别了限制，没有关闭既有门槛或宣称新的规范处理已实现。

密度处方方面，我要求修正了审查初稿的过强措辞。较早DDRHF文章明确用电流零分量定义rho_b；Fuchs等则说明协变的矢量密度依赖应由四流不变量构造。前者的静态定义不能自动证明后者错误，后者也不能代替本项目的奇核基准。当前准确说法是采用PKA1参数化的已声明协变延拓，空间重排须从同一泛函求导，奇核响应仍待验证。[Long等，Eq.8前的定义](https://arxiv.org/pdf/nucl-th/0608009)，[Fuchs等，Sec.II](https://harvest.aps.org/v2/journals/articles/10.1103/PhysRevC.52.3043/fulltext)。

负能基底用于展开完备性，与选择哪些准粒子支构造密度是两件事。DIRHB Eqs.46–48区分了配对情况下的粒子/海支；它对某些海项的省略也是近似，并未给本项目通用的海分量数值阈值。全G/F、全J配对则有形变RHFB的模型先例；保留nn、pp而不加入pn是本版本明确边界，不代表已覆盖pn关联。[DIRHB](https://arxiv.org/pdf/1403.4039)，[Geng–Long，配对部分及Appendix B](https://arxiv.org/pdf/2202.00482)。

本轮另核实了中断前计算的真实终态：受3 GiB保护的角网格加密计算已正常退出，并非需要重启的任务。同一份小盒NN密度保持L=2，角网格由3×6加密到7×14：PH总能量变化−4.04549 keV，但rho-T Fock变化−14.27729 keV；中子、质子完整场最大元素分别变化0.121553、0.104228 MeV。这里总能量有通道抵消，不能以其小于10 keV就宣布角向收敛。两份密度逐数组完全相等，产物哈希通过，独立受限后处理见[结果](../outputs/validation/angular_review_evidence_20261015/diagnostic.json)。这是N=3、Z=2、D=48的集成样本，不能替代O17的空间收敛。

本轮已落实的代码改动仅为物理含义记录：联合训练报告/检查点现在明确写出驻定残差目标、密度与配对处方、现有阻塞门槛、无海未认证和能量极小值未认证。原参数、场和阻塞算法保留；5项训练入口/准入检查在1.5 GiB硬保护下通过。后续优先固定可验证的物理无海目标，再接入一致的受约束能量选择；同时完成阻塞规范/标签和角向/导数核独立对照。
