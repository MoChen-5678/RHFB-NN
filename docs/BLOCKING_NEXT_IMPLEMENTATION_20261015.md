# O17 odd-neutron blocking: next implementation boundary

This note is a design recommendation for the current no-diagonalization, no-refresh neural HFB path. It separates what the current representation establishes from what a future candidate search could establish. It does not certify the active O17 run.

## What the literature establishes

**Source result — odd number parity is preserved.** Robledo and Bertsch state that a generalized Thouless transformation preserves the number parity of a Bogoliubov transformation: an odd-parity initial (U,V) remains in the odd-particle sector under gradient iteration (Sec. III, especially the parity statement and following paragraph). They further say that the global odd-space minimum is found only if that space is “adequately sampled.” Their conclusion is about minimizing the energy functional over odd-parity Bogoliubov configurations, not about following a named quasiparticle. [Robledo & Bertsch, arXiv:1104.5453, Sec. III](https://arxiv.org/html/1104.5453v1#S3)

**Source result — identity-aware blocking uses more than odd parity.** Schunck et al. define a blocked HFB density (Eqs. 15a–b), then describe choosing the quasiparticle associated with a target single-particle state: at each iteration, compare the target orbital with the quasiparticle upper component (U_\mu) and time-reversed lower component (V_{\bar\mu}), and choose the largest overlap near the Fermi level (Sec. III). The target is initialized using single-particle states from a neighboring even-even nucleus. This procedure presupposes access to the current quasiparticle states and a specified physical single-particle target; it is not a rule for inferring a named quasiparticle from the generalized density alone. [Schunck et al., arXiv:0910.2164, Sec. III](https://arxiv.org/html/0910.2164#S3)

**Source result — symmetry blocks label distinct odd solutions.** Robledo and Bertsch explain that imposed blocks (for example, axial (K)) are conserved during iteration and can yield separate odd states; they also warn that symmetries accidentally present in the initial state may persist because the corresponding gradient can vanish (Sec. V). This supports varying physically justified seeds and avoiding accidental restrictions, but does not license inventing a symmetry label or candidate threshold. [Robledo & Bertsch, arXiv:1104.5453, Sec. V](https://arxiv.org/html/1104.5453v1#S5)

## What follows for the current NN representation

The current model establishes odd number parity for an admissible pure trial. Its transported tag is an (R)-only occupied-plane continuation diagnostic. It is invariant to occupied-frame gauge changes, but that invariance is precisely why it cannot identify a particular Hamiltonian quasiparticle eigenmode. It reports whether a reference direction remains representable in the occupied plane; it does not certify a physical orbital label. A small or unresolved projection must therefore remain a diagnostic and must not reject a valid odd-parity trial.

The Schunck maximum-overlap prescription cannot be reproduced faithfully without the required current quasiparticle/single-particle spectral information. Under the explicit no-diagonalization constraint, do not replace that information with the overlap of arbitrary raw canonical columns, an (R)-transported vector, or an undocumented numerical cutoff. If a spectroscopic identity is required later, the model must expose a physically specified target and an identity-bearing variational object, or a preserved exact symmetry quantum number; a density-only tag is insufficient.

## Implementable candidate search and acceptance

1. **Name candidates by their provenance.** Start separate odd-parity runs from distinct, physically motivated initial configurations already available in the project (for example, archived seed labels or explicitly supplied orbital/channel labels). Keep the basis, functional, active space, constraints, and numerical settings identical. Do not invent candidate labels from raw column indices. A seed's index is provenance, not a final-state quasiparticle assignment.
2. **Let each candidate relax without identity gates.** Preserve the odd-parity sector and the structural validity conditions of the pure HFB state. Record transported-tag local/initial overlaps and unresolved status for diagnosis only. Do not use an empirical overlap value to accept or reject the physical trial.
3. **Accept stationary solutions by physical checks.** For each run, require the predeclared stationarity/convergence criteria, correct neutron/proton number treatment, odd number parity, valid pure-state structure, and finite energy evaluated with the same functional. These are solution-validity checks, not claims about quasiparticle identity.
4. **Rank accepted candidates by total energy.** Before comparison, require every candidate to belong to the same explicitly defined and independently validated no-sea variational branch. Parity, particle number, and a small commutator residual do not by themselves exclude Dirac-sea solutions or establish that a stationary point is a physical nuclear minimum. Then compare only converged candidates evaluated under the same setup. Report the result as “lowest-energy among the converged candidates searched,” alongside candidate provenance, energy, and convergence diagnostics. Robledo–Bertsch explicitly condition the odd-space minimum on adequate sampling; a finite candidate list cannot establish global minimality by itself. Distinct starts may also converge to the same solution, so deduplicate by density/state observables rather than gauge-dependent mode columns.

For the current trainer, the optimized loss is a stationarity residual (with number-control terms), not the variational energy. Lower loss establishes improved stationarity under that objective; it does not rank physical states. A zero full-commutator residual is still not sufficient to claim a stationary physical nuclear solution until the no-sea branch is established. Use the returned physical total energy only after the stationarity and branch checks above. Without diagonalization, a validated candidate-label set, or an identity-bearing model variable, the defensible O17 report is: **odd-parity stationary candidate; seed provenance recorded; physical quasiparticle identity and global-ground-state status uncertified.**

## Proposed reviewable runtime change (not implemented here)

Expose a candidate-list driver that accepts externally justified seed descriptors, runs the existing optimizer independently for each descriptor, and writes one row per run containing seed provenance, parity/particle-number checks, stationarity metrics, total energy, and tag diagnostics. Select the minimum total energy only among physically valid converged rows and label the scope as “searched candidates.” Keep tag diagnostics out of optimizer acceptance. If no physically justified candidate list is available, run/report the supplied seed only and mark the search incomplete rather than manufacturing an identity claim.
