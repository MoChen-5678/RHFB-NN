## 运行接口

在开发副本中运行，避免从父目录导入原包：

```bash
cd /home/ubuntu/rhf/DFT-RHF-NoRefresh/variants/blocked-rhfb

# 小空间算法验收，输出为 JSON 文件；未通过时退出码为 2。
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 .venv/bin/dpl-no-refresh \
  validate-rhfb-prototype --epochs 300 \
  --out outputs/validation/prototype_gate.json

# 核计算接口现阶段保存阻断报告并退出，不能生成核能量。
.venv/bin/dpl-no-refresh train-rhfb --z 8 --n 9 \
  --block-n auto --block-p none \
  --out outputs/validation/O17_gate
```

`train-rhfb` 接受 Z/N、盒半径、网格间距、κ 截断、各类活动轨道数、
阻塞初态、训练步数、随机种子和输出目录。模型固定 PKA1、D1S 强度 1、
complex128，刷新间隔只能为 0。奇奇核配置要求 n/p 各一个阻塞；
偶数粒子种类拒绝单阻塞配置。
当前 `auto` 是候选搜索接口占位，尚未进行自动候选态训练。
旧 `train-rmf` / `train-rhf` 接口保留。

按本轮补充要求，径向空间导数已单独对照张颖等人的论文核查。
论文五点 ADF 的系数、前/后向方向、大/小分量奇偶交换及厄米性
有独立测试；当前七点高阶扩展保持原样。公式、页码与边界适用范围见
[径向 ADF 核对](RHFB_ADF_AUDIT.md)。参数梯度的中心差分校验保持原样。

## 移动投影的驻定条件问题

基础原型采用 Δ=−Gχ。χ 本身在正能空间内，因此这一配对场也在同一
空间内，测试无法检验配对场跨 Dirac 海时的投影导数。
决定性对照另外采用 K=I+0.2S、Δ=−GKχKᵀ；S 的一部分耦合正常
Dirac 算符的正、负能扇区。0.2 和 G 都是玩具模型压力测试参数，
不是 D1S 强度修改，也不参与核计算。

当 P=P+[h(ρ)] 随密度变化时，χ=PχPᵀ 的变分包含

\[
 \delta\chi=(\delta P)\chi+\chi(\delta P)^T
              +P\,\delta\chi_{\mathrm{internal}}P^T.
\]

本原型中每次冻结正常算符正能空间的独立阻塞 BdG 参考方程只包含内部变分。
若 Δ 跨正、负能空间，配对能的
Re〈Δ,(δP)χ+χ(δP)ᵀ〉通常不为零。
正常场部分因 h 与其精确谱投影可交换而不能直接消除这一配对项。
因此，将 P 的导数完整纳入训练，并不自动得到常规无海阻塞 RHFB 的
相同驻定条件。不能通过悄悄截断这些导数宣布等价。

对照从独立收敛参考态出发，直接测量移动投影下的正则切向梯度，
去掉粒子数切向分量（避免把化学势定义差别当成物理差别），
并检查投影迭代数增加后的梯度稳定性和该方向的数值导数。
固定场、移动场、海泄漏、跨海配对场、数目和优化器收敛分别记录。
若参考态在两种驻定条件下不一致，按本轮方案保留实现并阻断生产核计算；
后续需要重新推导与常规 RHFB 一致的无海变分处方及参考方程。

## 理论来源与模型边界

上级目录 `RHF-e.pdf` 中的一般顶角是后续完整非球形 PKA1 的基础；
原球形磁量子数求和只用于无流球形退化校验，不能代替奇核显式阻塞。
PKA1 形变 RHFB 文献：[arXiv:2202.00482](https://arxiv.org/abs/2202.00482)。
正则变分路径参考 [arXiv:1205.4443](https://arxiv.org/abs/1205.4443)；
逆 Hamiltonian HFB 参考 [arXiv:1304.4697](https://arxiv.org/abs/1304.4697)，
后者不证明本项目完整相对论移动投影约束的等价性。
D1S 数值出处与 M₂ 表格舍入差异记录于 `rhfb/pairing.py`。
本版本不包含 pn 配对、强度拟合、粒子数投影或等填充近似。
