# 沙盒外 GPU 授权

用户最新指示仅允许使用物理编号 **1**。本机当前对应 UUID 为
`GPU-7a8e66fa-4e34-6c9a-cf77-303aa06921c8`。以后每次启动须重新核对
编号和 UUID；不允许回退到物理 GPU 0，也不终止其他任务。

启动器只向计算进程暴露选中的一张卡，所以程序内的 `cuda:0` 对应物理
GPU 1。启动器与 `configure_cuda` 都检查物理编号；后者在可能初始化
CUDA 上下文之前拒绝未经授权的设备。主存硬限额、零交换、显存预算、
忙卡拒绝和单数值任务规则均保留。

发生在这条新指示之前。它已退出，原始 UUID 和资源证据保持原样。
不得把那份结果改称为 GPU 1 上的新计算。
