# 参考文献与公式映射

发布包不分发论文和书籍 PDF。用户可在本地建立 `references/` 目录存放合法副本，该目录不参与程序运行。

1. Physical Review Letters 133, 076401 (2024)，AI2DFT/深度学习变分思想。对应网络参数化变分对象、物理泛函提供无监督梯度、外部参考不进入损失的总体方法。
2. Zhang Ying 等，Chinese Physics C 49, 014106 (2025)。对应球对称 Dirac 方程的非对称有限差分；本程序使用七点扩展 ADF，并显式构造前后向两个微分块。
3. 当前项目核物理教材的 RMF 章节。对应标量/矢量密度、介子场方程、径向 Dirac 方程、能量泛函、重排项和核半径定义。
4. Core-1204 Fortran 实现。用于核对参数、通道符号、网格、积分口径、重排势和最终外部 SCF 数值，但其 SCF 迭代不进入网络损失。

文档中的“严格”指离散程序与上述 RMF 方程、通道定义及硬约束一致，不表示当前程序已覆盖配对、形变或 RHF 非局域交换。
