## 新增的确定空间宇称候选

已有一般复数后端允许内禀反射破缺。为 O17 另加保守空间宇称的候选：轨道修正和正则 Bogoliubov 生成元只连接同空间宇称；仍允许所有磁分量混合、时间反演破缺以及轨道离开初始活动子空间。

Dirac 空间反射为 `βψ(-r)`，故 G、F 的**径向系数**具有相同的上分量轨道宇称。不能把下分量球谐函数的相反宇称直接用作系数宇称。独立的坐标反射测试已检查此处。

这与 ADF 选择前/后差分时所用的**负径向坐标延拓奇偶性**不同：约化 G 的延拓为 `(-1)^(l+1)`，约化 F 的延拓相反，所以它们使用相反的 ADF 方向。物理空间反射还包括角坐标反射和 β，两种奇偶性不能混用。

数宇称与空间宇称分别检查。对不连接相反空间宇称的纯 Gaussian 状态，多体空间宇称是 `(-1)^N_minus`，可由负空间宇称子块的数宇称 Pfaffian 得到。这是本报告的推导，不是所引论文提供的现成算法；两个明确的有限 Fock 空间配对态已独立验证它。诊断不指定最终角动量 J。

新候选相关测试与已有网络测试合计 **13 通过、1 CUDA 跳过**。这是结构和可训练性检查，不是核物理验收。

## 独立时间反演检查

以保存的神经网络因子为输入，不再优化。取 `Θ=diag(iσ_y,iσ_y)K`，按球谐和 Clebsch–Gordan 相位推导系数映射，并直接与四分量坐标 spinor 的反幺正变换对照。上下径向分量的相位相同：下分量球谐相位与共轭 `iF` 的负号抵消。

| 必要对称性检查 | 误差 |
|---|---:|
| 坐标 spinor 的 Θ 映射 | ≤2.86×10⁻¹⁷ |
| Θ²=−1 | 0 |
| 空间流反向 `j + j_Theta` | ≤1.74×10⁻¹⁸ |
| 全部能量分项的最大差 / MeV | 1.14×10⁻¹³ |
| 总能量差 / MeV | −2.27×10⁻¹³ |

中子空间流最大值约 0.00194 fm⁻³，故不是在所有时间奇源均为零的输入上做空检查。中子、质子同时时间反演；没有把它们平均成等填充密度。完整 PKA1 已实现通道、接触补偿和 D1S 均参与对照。Torch、NumPy 的八个特征值 API 在能量计算中被禁止且尝试数均为零。源文件前后校验一致。这只验证时间反演协变性；它不检验 moving-projector energy response，也不能证明 no-sea quasiparticle branch 等价。

## 物理审查决定后续工作

1. 从 RHF-e 和原始 Lagrangian 独立推导 ρ-T、VT/TV、π-PV 的直接及交换顶角，已完成本轮小空间离散核对。独立参考先出现复数交换索引错误，再在 mixed 项把单导数轴求和重复三次；两份失败数据及源码均保存。修正独立参考后，这些直接/交换项的最大差为 `4.44×10⁻¹⁶ MeV`，**没有因此改生产泛函**。该核对共享原始离散 Green 核，故不能据此宣布连续传播核、接触补偿总归一或真实核结果正确。完整逐 Lorentz/空间轴和有序 n/p 对数据见 [专项报告](PKA1_CURRENT_VERTEX_REFERENCE_20261006.md)。
2. 移动投影的变分核查已得结论：`[H_a,R_a]=0` 是固定 `P` 的 active-space 方程，不一般等于 `E(P_+(h[ρ]),R_a)` 的 Euler 方程。若 `P` 是同一正常场 `h=δE_ph/δρ` 的精确谱投影且 `ρ=PρP`，normal projector-response 一阶项抵消；full `Δ` 的 `P_+/P_-` pairing cross-block contraction 则一般还在。当前根方程没有这项，自动微分残差雅可比不等于 composed-energy 梯度。该结论不判断特定 O17 状态的 pairing response 数值；它必须用 projector derivative 与 full D1S `Δ` 单独评估。推导、六维原始空间中的纯态奇数解析例和修正判据见[移动投影审计](MOVING_PROJECTOR_PHYSICS_AUDIT_20261006.md)；更广的处方边界见 [已有驻定处方说明](RHFB_PHYSICAL_EQUATIONS_DECISION_20261006.md)。
3. 对阻塞参考先检查分支与稳定性，再用它比较网络。独立密度数宇称检查进一步发现：最新小空间参考从奇数参考态出发，第一次 BdG 伙伴对选择后实际变成偶数宇称，虽然对象标签仍称奇数。该数据不仅未收敛，而且不能作为奇核参考。须先核验明确声明的偶数参考真空，再仅翻转指定阻塞模式；每次构造密度后从密度独立计算数宇称，不能只相信标签。一般时间奇场下的谱真空不保证偶数宇称，不能把“所有正能准粒子均湮灭该态”与“偶数参考态”混为一谈。随后才能再核查稳定性和最低分支。
   独立参考选择器已按固定二次场的宇称修正：先计算谱真空的实际数宇称，需要时先构造偶数参考，再仅阻塞指定模式。含非零未阻塞配对的代数测试及时间奇参考真空测试通过。此次没有重新运行自洽参考求解，不提供已收敛奇核参考，见[分支专项审查](TRACKED_BDG_REFERENCE_PHYSICAL_AUDIT_20261006.md)。
4. 在相同物理处方通过后，再做正式空间、多个阻塞候选及网格收敛。原始 PKA1 数值说明采用明显更细的径向网格；当前粗网格数据不提供真实核能量精度证据。另从 RHFB Eq. (9) 的传播子建立了独立高斯源 Fourier 积分及独立一维积分参考。在同一 R=12 fm、b=2 fm、N=1 源上，h=0.8 fm 的 σ/ω bare 传播积分相对误差为 34.88%/76.98%，h=0.2 fm 仍为 2.268%/5.442%；源归一误差 ≤8×10⁻¹⁵。h=0.05 fm 降至 0.1421%/0.3430%。这直接说明短程卷积欠分辨，但只验证 l=0、常耦合、无导数 bare 核，不能当作实际 O17 总能量误差。生产核没有改动，见[传播积分专项核对](GREEN_PROPAGATOR_GAUSSIAN_REFERENCE_20261006.md)。

包含上述空间宇称、网络、端点顶角、移动投影、阻塞参考及 bare 传播核检查的联合测试为 30 项通过、1 项 CUDA 检查跳过、0 失败，见[联合测试 XML](../outputs/validation/physics_logic_integrated_20261006_v3.xml)。这些是各自注明范围的验证，不能替代物理收敛验收。

另按 DIRHB 的无海分支公式建立了明确区分两个处方的[独立 Fock/BdG 算例](NO_SEA_BRANCH_NORMAL_PROJECTION_COUNTEREXAMPLE_20261006.md)。规定的正常正负模式之间配对场非零时，标准分支纯态驻定密度与严格 normal-P 支持密度可不同；大 Dirac 间隙使差异小，不使它严格为零。该算例不是 D1S 或 O17 参考。

同一保存的实际神经网络 O17 状态又完成了完整原始空间 D1S `ΔQ*` 作用的后处理诊断：中子/质子 `‖P_-^free Δ (P_+^free)* Q*‖F` 为 `8.56×10⁻⁴ / 9.42×10⁻⁴ MeV`，活动 Q 框架外的 `ΔQ*` 范数占比为 `70.17% / 62.74%`。重构活动配对场与存档最大差小于 `6.6×10⁻¹⁸ MeV`，中子/质子数宇称独立计算为 −1/+1。旧 stationarity 数据与新候选的 Q 不同，故没有冒用旧场数值。该诊断只测自由 Dirac 投影在保存框架上的作用，不是完整算符块范数，更不是相互作用 h 的移动投影响应；后者仍未计算。见[专项数据及边界](../outputs/validation/O17_d1s_cross_dirac_pairing_20261006/REPORT.md)。
