# PKA1 完整通道与首轮变分审计

## 1. 审计依据

本审计只使用仓库内的两类物理依据：

1. `核物理(1).pdf` 式 (1.1)、(1.4)-(1.5)、(1.30)-(1.32)；
2. `0204872龙文辉_5.0.pdf` 第 2 章及附录 A，特别是 pion-PV、rho-T、rho-VT 的球对称推导。

`Core-1204` 只用于核对这些公式的离散实现和数值结果，不向神经网络提供训练标签。

书中相互作用拉格朗日量为

```text
L_I = L_sigma-S + L_omega-V + L_rho-V + L_rho-T + L_pi-PV + L_A-V.
```

消去介子场后，rho 的 vector 和 tensor 顶角还产生两个有序交叉收缩
`V(r)T(r')` 与 `T(r)V(r')`。因此 PKA1 能量泛函必须包含下表中的全部项。

## 2. 完整通道表

| 拉格朗日顶角 | Hartree 直接项 | Fock 交换项 | 程序能量键 |
| --- | --- | --- | --- |
| sigma-S | scalar | scalar | `E_sigma`, `E_sigma_fock` |
| omega-V | time-like | time-like + space-like | `E_omega`, `E_omega_fock_time`, `E_omega_fock_space` |
| rho-V | time-like isovector | time-like + space-like isovector | `E_rho`, `E_rho_fock_time`, `E_rho_fock_space` |
| rho-T | tensor source | `T1` (nu=0) + `T2` (nu=1,2,3) | `E_rho_tensor_direct`, `E_rho_tensor_fock_time`, `E_rho_tensor_fock_space` |
| rho-VT | both vertex orders | both vertex orders and time/space pieces | `E_rho_vt_direct`, `E_rho_vector_tensor_fock`, `E_rho_tensor_vector_fock` |
| pion-PV | exactly zero for a static spherical even-even ground state | finite range + contact subtraction | `E_pion_fock` |
| photon A-V | proton time-like | proton time-like + space-like | `E_coul`, `E_coul_fock_time`, `E_coul_fock_space` |

`pi` 的 Hartree 贡献为零是球对称偶偶核基态的对称性结论，不是漏项；
`Core-1204/Expect.f90` 也将该项严格输出为零。

## 3. Density variables and sums

The network varies the occupied one-body density matrix. For each species
`q` and `kappa` block,

```text
P_(q,kappa) = Q n Q^T,
R^(mu,nu)_(q,kappa)(r,r')
  = (2j+1) sum_n v_(n,kappa,q)^2
    u^(mu)_(n,kappa,q)(r) u^(nu)_(n,kappa,q)(r').
```

The principal-state sum is performed first inside fixed `(q,kappa)`, followed
by the source-block `kappa_b` sum. The four nonlocal components `GG/GF/FG/FF`
are retained. Hartree scalar, vector and tensor densities are diagonal
contractions of this same density matrix; no separate local-density model is
introduced.

## 4. Density dependence and rearrangement

Every PKA1 vertex remains inside the PyTorch graph:

```text
g_sigma(rho_b), g_omega(rho_b), g_rho(rho_b),
f_pi(rho_b), f_rho(rho_b).
```

Consequently `dE_RHF/dP` contains the direct and exchange rearrangement
self-energies from all five density-dependent vertices. Rearrangement is a
self-energy generated by variation; it is not added again as an independent
energy term.

The training Hamiltonian is

```text
h_(q,kappa) = (2j+1)^(-1) dE_RHF / dP_(q,kappa),
```

and the embedded Euler-Lagrange residual is

```text
(I - Q Q^T) h Q.
```

No Dirac equation or RHF eigenproblem is solved during an epoch. A local
Hamiltonian is diagonalized only once to define the fixed positive-energy
no-sea space.

## 5. New fail-fast checks

`dpl_rhf/rhf/functional.py` now owns an explicit PKA1 direct/Fock manifest.
Every forward pass verifies:

1. every required energy component exists;
2. the sum of the six direct groups equals `E_direct`;
3. the sum of the seven Fock groups equals `E_fock`.

On the first forward pass, `dpl_rhf/rhf/backend.py` separately differentiates
all 13 groups with respect to the density projectors. A disconnected or
non-finite gradient aborts before the first optimizer update. The resulting
norms are stored in `summary.json` under
`physics.first_forward_complete_channel_gradient_audit`.

For PKA1 O16 at epoch 0 all groups are connected. The gradients most relevant
to the PKA1 extension are:

## 7. Reproduction

```bash
conda activate torch_env

python -m dpl_rhf.cli.rhf_train \
  --model PKA1 --z 8 --n 8 --a 16 --epochs 0 --device cuda \
  --out outputs/rhf/PKA1/O16_full_channel_epoch0_audit

python scripts/audit_rhf_same_density.py --model PKA1 --z 8 --n 8 --a 16
python scripts/audit_rhf_same_density.py --model PKA1 --z 20 --n 20 --a 40
```
