# RHF examples

- `PKA1_O16_memory.sh`: foreground 500-epoch O16 run using host-memory saved tensors.
- `PKA1_Sn132_disk.sh`: persistent `nohup` Sn132 run using disk saved tensors.
- `compare_PKA1_O16_with_Core.sh`: final Core comparison, including all nonlocal density `R` blocks.

Run `../../setup_env.sh` once before using these examples.
